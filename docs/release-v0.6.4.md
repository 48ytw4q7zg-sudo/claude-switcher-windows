## 本版修复

### 新引入的严重缺陷（P0-NEW-01~04）

| 编号 | 缺陷 | 修复 |
| --- | --- | --- |
| **P0-NEW-01** | **跨进程锁嵌套死锁**：`restore_all → restore → release_all_verified` 三层申请同一文件锁，Windows 上自我等待，紧急恢复卡死 | 改为**进程内可重入锁**（HOLD_DEPTH 计数），嵌套复用外层锁，只有最外层释放；跨进程仍严格互斥。加 10 秒超时回归测试 |
| **P0-NEW-02** | 删除失败仍报恢复成功：`release_all()` 在 `verified=false` 时仍返回 `Ok`，上层错误清除熔断状态 | 删除 `release_all()`，统一 `release_all_verified()`；未验证时返回 Err；监控与命令层只在 verified 时清状态 |
| **P0-NEW-03** | Desktop 回滚**选错备份**：用「扫描取最新」猜测备份路径，可能选中其他账号历史备份 | 新增 `DesktopTransaction`，由切换函数精确回传本次备份；原本无活目录时回滚为「不存在」 |
| **P0-NEW-04** | 状态损坏时两个守护器行为**相反** | `Gate` 增加 `intent`，`decide()` 要求严格 `Armed`（Disarmed/Unknown 都停止新副作用），与 `guard_tick` 一致 |

### 遗留 P0

| 编号 | 缺陷 | 修复 |
| --- | --- | --- |
| **P0-05** | 未接入 Clash 时不熔断：跳过探测 → 全 Unverified → 不累计失败 → 失去保护 | 接入路径独立防抖（`access:uncovered` 计数），达阈值并入 `should_trip`；恢复后清零 |
