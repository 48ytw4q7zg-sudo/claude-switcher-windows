**目标：** 保留当前全部未提交成果，完成 VallierDev、YOURSJEYO 与 ClaudeGuard 的 Windows 功能融合，所有产品界面使用简体中文，并在实际验证通过后提交和推送 GitHub。

**依据：** `docs/full-audit-progress-2026-11-02.md`、`docs/upstream-baseline.md`、三份指定 Codex JSONL 历史，以及后续固定的上游源码清单。

## 全局约束

- 不覆盖、回滚或丢失当前未提交修改；项目内原子提交，推送使用普通 `git push`。
- 所有可视化产品文案为简体中文；品牌、协议、路径和配置标识保持英文。
- 新行为先写能复现原缺陷的测试，确认 RED 后最小实现，再跑 GREEN。
- 不读取、复制或输出真实账号凭据；上游下载使用独立空目录，不执行其中脚本。
- 同一 Windows 用户的同一 WSL 发行版同步需要跨进程互斥；这不是 Claude 官方凭据锁。
- 不将“代码存在”“静态阅读”或“合成测试”写成真实系统验收。
