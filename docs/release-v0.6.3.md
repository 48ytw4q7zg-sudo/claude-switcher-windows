# v0.6.3 — 第五轮审计 P0 收口（小修订版）

发布日期：2026-11-04
基线：v0.6.2（`0388300`）→ 本版
依据：GPT-6 第五轮源码审计（固定 `0388300`）

## 本版修复的 9 项 P0

| 编号 | 缺陷 | 修复要点 |
| --- | --- | --- |
| **P0-01** | 停用意图不可靠（写失败静默、状态损坏当 Armed） | `disarm/rearm` 返回 Result；新增 `ProtectionIntent` 三态（Armed/Disarmed/**Unknown**）；`guard_tick` 检查意图，Unknown 也跳过；新增 `egate_rearm` 与「恢复暂停」分离 |
| **P0-02** | 系统操作无统一执行权 | 新增 `egate_lock`：fs4 跨进程锁，五类操作（隔离/断网/恢复网络/解除隔离/完整恢复）全部持锁；监控用非阻塞避免卡死 |
| **P0-03** | 断网账本计划被进度覆盖 | `CutState` 拆分 `planned_adapters`（永不缩减）与 `completed_adapters`；恢复以完整计划为准 |
| **P0-04** | 防火墙删除未验证真消失 | 新增 `ReleaseReport`；`release_all_verified()` 删除后回查；`rule_count()` 也统计旧版前缀（排除 Cut All）；`restore_all` 只在 verified 时设 isolation_ok |
| **P0-05** | 网卡恢复失败仍解除断网 | 网卡失败时保留全局阻断规则，进入待恢复状态，避免断网真空 |
| **P0-06** | 重启后熔断状态归零 | `rebuild_trip_state_from_system()`：启动时查询实际规则重建状态（有规则→部分熔断，保守触发补齐） |
| **P0-07** | Desktop 文件与账号库不可共同提交 | with_store 失败且文件已切换时，用备份回滚活目录；回滚失败保留备份路径 |
| **P0-08** | Clash 先改 Merge 后读 Script | 所有读取与校验提前到任何写入之前；unknown 模式预检即返回；Script 读取失败立即中止 |
| **P0-10** | 暂停被当成启动放行 | `decide()` 移除「暂停即允许」；暂停只停止自动副作用，已熔断/出口未通过仍阻止启动 |
| **P0-11** | 环境账本损坏当成没改动 | `load()` 改 `Result<Option<...>>`；损坏返回 Err，不被当成「无改动」或清理 |
